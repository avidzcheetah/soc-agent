## 1. Executive Summary & Validated Benchmark Metrics

This report presents the validated, defensible research results for the autonomous Security Operations Center (SOC) incident response system. The core objective is **response action optimization** (selecting the most effective mitigation action from a 20-action discrete CISA space) given alerts generated by upstream detection systems (such as Wazuh SIEM and OSQuery).

## 3. Attack Simulation, Telemetry, and Detection Pipeline

### 3.1 Architectural Scope: Alert Ingestion vs. Response Action Selection
Our architecture cleanly separates **Detection** from **Response**:
1. **Detection & Telemetry Layer:** External sensors (Wazuh SIEM, OSQuery, host logs) collect endpoint and network events, firing detection rules when anomalies or signatures occur.
2. **Contextual Encoding Layer:** The incident alert text and telemetry attributes are encoded into a continuous 768-dimensional latent vector via our fine-tuned frozen SecBERT encoder (`pooler_output`).
3. **Response Optimization Layer:** The PPO Actor policy consumes the state representation to select the optimal mitigation action out of 20 discrete CISA actions.

```
┌─────────────────────────────────┐       ┌─────────────────────────────────┐
│     Adversary Simulation        │       │    Host & Network Telemetry     │
│   • MITRE Caldera Operations    │ ────> │   • Wazuh Manager / Indexer     │
│   • Atomic Red Team TTPs        │       │   • OSQuery Process / Socket    │
└─────────────────────────────────┘       └─────────────────────────────────┘
                                                           │
                                                           ▼ (Alert JSON & Logs)
┌─────────────────────────────────┐       ┌─────────────────────────────────┐
│       PPO + ATGP Agent          │       │      SecBERT Encoder (Frozen)   │
│   • 20-Action Discrete Decision │ <──── │   • 768-Dim Semantic Embedding  │
│   • Action: Containment/Logging │       │   • Domain-Specific Cyber Latent│
└─────────────────────────────────┘       └─────────────────────────────────┘
```

### 3.2 Real-World Incident Datasets & Provenance
The models were trained and benchmarked across **15,390 deduplicated incident records**:
- **CISSM Cyber Events Database:** 14,370 records of real-world historical cyber incidents.
- **rcATT MITRE ATT&CK Corpus:** 1,020 detailed threat intelligence reports with mapped ATT&CK techniques.
- **Split Strategy:** Strict stratified 80% train (12,312 records), 10% validation (1,539 records), and 10% test (1,539 records).

## 4. System Action Selection & Per-Class Performance Breakdown

### 4.1 What Responses Our System Gave
The agent operates over the **20 discrete CISA incident response actions** defined in `data/action_space.csv`:
- **For C2 & Network Exfiltration:** The system accurately selected **`block_dest_ip` (Action 4)** and **`isolate_host` (Action 7)**, blocking egress channels while capturing indicators.
- **For Credential Theft & Lateral Movement:** The agent avoided ineffective process killing, instead selecting **`reset_credentials` (Action 11, F1: 92.1%)** and **`disable_account` (Action 12, F1: 95.9%)**.
- **For Sudo & Scheduled Task Persistence:** The agent prioritized **`remove_persistence` (Action 13, F1: 78.4%)** and account revocation.
- **For Benign Administrative Events:** The agent selected **`monitor` (Action 0, F1: 99.2%)** and **`enable_deep_logging` (Action 1, F1: 76.9%)**, achieving a low **False Positive Rate of 0.14%** and avoiding disruptive host isolation on legitimate servers.

## 5. Slide-Ready Presentation Bullets

### Slide 1: The Research Problem & Core Innovation
- **Challenge:** Modern SOC analysts are overwhelmed by alert fatigue. Existing SOAR playbooks are rigid and cause business disruption on benign administrative tasks.
- **Our Approach:** Decoupled architecture:
  - **Detection & Telemetry:** Wazuh SIEM + OSQuery + MITRE Caldera generate alerts and host telemetry.
  - **Contextual Representation:** Fine-tuned SecBERT encodes incident text into 768-dimensional semantic embeddings.
  - **Decision Optimization:** Proximal Policy Optimization with **Adaptive Teacher-Guided Preservation (ATGP)** learns autonomous incident response action selection over a 20-action CISA mitigation space.

### Slide 2: Key Empirical Results
- **94.74% Overall Accuracy** and **94.61% Weighted F1-score** across 1,539 untouched test incidents.
- **Surpasses the Supervised SecBERT Baseline:**
  - Macro F1 improved from **71.21%** to **71.64%** (+0.43%).
  - Matthews Correlation Coefficient (MCC) improved to **+0.9378**.
  - Significant boost in challenging minority classes (e.g., `remove_persistence` F1 reached **78.43%**, `restore_defense_config` F1 reached **33.33%**).
- **Extremely Low False Positive Disruption:** **0.14% False Positive Rate** on non-malicious tasks, avoiding unnecessary host isolations.
- **Top-2 Action Accuracy:** **97.08%** — the correct remediation action is within the top-2 recommendations over 97% of the time.

### Slide 3: Comparison with Existing Work
- **Superior to Rule-Based SOAR:** Eliminates the high false-disruption rate (57.1% in heuristic playbooks) while handling novel multi-stage variants.
- **Superior to Non-Language RL (DQN / ARCS):** Avoids policy collapse and the "isolate-everything" trap.
- **Superior to Static Text Classifiers:** Bridges the gap between static alert triage and dynamic, autonomous multi-action decision-making.
